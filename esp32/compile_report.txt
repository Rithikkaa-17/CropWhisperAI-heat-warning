CropWhisperAI firmware - ESP32 compile report
Toolchain: arduino-cli 1.1.1, arduino-esp32 core 2.0.17, board "ESP32 Dev Module" (espressif:esp32:esp32), xtensa-esp32-elf-gcc (-Os)
Libraries: DHT sensor library 1.4.7, Adafruit Unified Sensor 1.1.15, OneWire 2.3.8, DallasTemperature 4.0.6, BH1750 1.3.0,
           Adafruit SSD1306 2.5.17, Adafruit GFX 1.12.6, Adafruit BusIO 1.17.4
Compiler warnings (-Wall): none

Full firmware (sensors + validation/carry-forward + model + OLED + Wi-Fi/HTTP upload + NTP):
  Sketch uses 798085 bytes (60%) of program storage space. Maximum is 1310720 bytes.
  Global variables use 53620 bytes (16%) of dynamic memory, leaving 274060 bytes for local variables. Maximum is 327680 bytes.

Model + streaming features only (cropwhisper_model.h, xtensa-esp32-elf-gcc -Os -mlongcalls):
  text 1016 bytes (includes 32-byte weight table), data 4 bytes, bss 6916 bytes (6912-byte ring buffer + counter)

Inference time: not measurable without hardware - read the inference_us column of the Serial CSV log.

NOTE (revision 1): these figures are for firmware v1.0. Firmware v1.1 (this repository) adds the warm-up and
max-consecutive-invalid-reading guards and uses a feature set re-selected after the quality-control correction
(illuminance/BH1750 no longer selected). v1.1 was not physically re-flashed and re-measured on ESP32 hardware;
the manuscript (Table 12, Section 4.7) discloses this and carries the v1.0 figures forward with that caveat.
